About Me

I’m Ramazan Toktav - a Junior Frontend Developer and Web Designer based in Aktau. I build modern, responsive, and performance-focused web interfaces from scratch. My background combines technical education in web development from ATKS College with a sharp eye for clean design and intuitive user experience. I prefer keeping things lightweight and efficient - no bloated code or unnecessary dependencies, just solid architecture built with pure HTML5, CSS3, and JavaScript, styled using modern layout techniques like Flexbox, CSS Grid, and fluid typography. When designing interfaces, I use Figma to map out every detail before bringing it to life in code. Whether it's structuring a clean semantic layout, optimizing for mobile devices, or crafting seamless user flows, I focus on delivering functional and visually polished web projects.

Frontend Core: HTML5, CSS3, JavaScript (ES6+)

Layout & Styling: Flexbox, CSS Grid, BEM methodology, Responsive Web Design, clamp() fluid typography

Design & Tools: Figma, Git & GitHub, VS Code

Education: ATKS College (Web Design & Frontend Development)
