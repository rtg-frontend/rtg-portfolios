## 🛠️ Tech Stack & Features
- **Core:** Pure HTML5, CSS3, JavaScript (ES6+)
- **Layout & Styling:** Flexbox, CSS Grid, BEM methodology, `clamp()` fluid typography
- **Design Philosophy:** Minimalist dark theme (warm charcoal palette & amber text accents), zero bloated frameworks or unnecessary dependencies.
- **Icons:** Font Awesome (via jsDelivr CDN)
- **Typography:** Inter (Google Fonts)
